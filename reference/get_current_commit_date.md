# Get the date of the currently checked out commit

Get the date of the currently checked out commit

## Usage

``` r
get_current_commit_date(repo)
```

## Arguments

- repo:

  dataset name: 'all_basiclevel', 'reliability', etc.

## Value

A string with the date.

## Examples

``` r

if (FALSE) { # \dontrun{
get_current_commit_date('all_basiclevel')
} # }
```
