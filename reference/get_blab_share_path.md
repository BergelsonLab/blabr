# Find BLab share

Find BLab share

## Usage

``` r
get_blab_share_path(check_exists = TRUE)
```

## Arguments

- check_exists:

  Should the function check that the path exists (accessible)

## Value

Path to the BLab share

## Examples

``` r
if (FALSE) { # \dontrun{
blab_share <- get_blab_share_path()
} # }
```
