# Calculate percentile scores for each metric in SEEDLingS CDI spreadsheet and add them as new column.

Calculate percentile scores for each metric in SEEDLingS CDI spreadsheet
and add them as new column.

## Usage

``` r
calculate_percentile(df, norms, col, both)
```

## Arguments

- df:

  SEEDLingS CDI spreadsheet as retrieved by
  [`get_seedlings_cdi()`](http://bergelsonlab.com/blabr/reference/get_seedlings_cdi.md)

- norms:

  Norm conversion table to use, as generated by
  [`load_cdi_norms_wg()`](http://bergelsonlab.com/blabr/reference/load_cdi_norms_wg.md)

- col:

  String indicating which metric (i.e. which column) to convert to
  percentile score

- both:

  A boolean value, Indicating whether we're calculating percentile score
  by sex or for both sexes.

## Details

This function will modify the existing spreadsheet by adding a new
column named, say `CDIcomp-percentile-both` (if `both=TRUE`) or
`CDIcomp-percentile-sex` (if `both=FALSE`), if called on col `CDIcomp`.
For each `CDIcomp` score, if will first match the age and find the
closest score less than or equal to the child's score, and return the
highest percentile that score matched to. The new column will be next to
their original score column
