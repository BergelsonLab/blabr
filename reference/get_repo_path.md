# Absolute path to a dataset folder

Absolute path to a dataset folder

## Usage

``` r
get_repo_path(repo)
```

## Arguments

- repo:

  dataset name: 'all_basiclevel', 'reliability', etc.

## Value

absolute path as a string

## Examples

``` r
if (FALSE) { # \dontrun{
get_repo_path('all_basiclevel')
} # }
```
