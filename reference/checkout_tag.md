# Download the dataset version specified by a tag

Download the dataset version specified by a tag

## Usage

``` r
checkout_tag(repo, tag)
```

## Arguments

- repo:

  dataset name: 'all_basiclevel', 'reliability', etc.

- tag:

  tag label as a string

## Examples

``` r
if (FALSE) { # \dontrun{
checkout_tag('all_basiclevel', '0.1.0')
} # }
```
